# Inovare Pintura — pacote de produção para Claude Code

Este diretório é a fonte de verdade para o desenvolvimento do novo site da
Inovare Pintura. Ele reúne direção criativa, copy em português europeu,
arquitetura, scrollytelling, plano de sprints, critérios de qualidade, dados e
assets reais.

## Como começar

1. Copie este diretório para a raiz do repositório do site.
2. Mantenha `CLAUDE.md` na raiz do projeto.
3. Abra o Claude Code na raiz.
4. Cole o conteúdo de `prompts/START-HERE-PROMPT.md`.
5. O agente deve começar pelo Sprint 0 e produzir o diagnóstico antes de
   escrever código.

## Resultado esperado

Um site institucional premium, rápido e orientado a conversão, com:

- abertura cinematográfica controlada pelo scroll;
- narrativa visual baseada numa obra real;
- transição de tinta nas cores da marca;
- navegação simples e acessível;
- serviços apresentados com clareza;
- galeria de trabalhos reais com lightbox;
- contacto direto por telefone, WhatsApp, e-mail e Instagram;
- SEO local para Olhão e região do Algarve;
- métricas, acessibilidade e desempenho verificáveis.

## Princípio editorial

As imagens geradas constroem a atmosfera da abertura. As fotografias reais
provam o trabalho. Nunca apresentar uma imagem gerada como obra executada pela
empresa.
